1. Explica la importancia de un motor de base de datos para manipular una base de datos o su conjunto, y detalla qué papel desempeña el SGDB al interactuar con una base de datos.
El motor de base de datos es la parte del software que hace funcionar la base de datos. Es como el "corazón" que se encarga de guardar, buscar, cambiar y borrar los datos. Sin el motor, la base de datos no podría hacer nada. El SGBD es el programa completo que usa ese motor y además organiza todo lo que se hace con la base de datos. El SGBD ayuda a crear usuarios, dar permisos, hacer copias de seguridad y proteger los datos. Es como el "jefe" que organiza y cuida toda la información de la base de datos.
 
1. Indica qué protocolos tiene disponible el sistema de gestión de bases de datos para conectarse con otras bases de datos, tanto de tipo local como de tipo remoto.
Los SGBD usan protocolos de red que permiten conectarse a una base de datos desde la misma computadora (los cuales son locales) o desde otra computadora por Internet o red (los cuales son remotos).
Algunos de estos protocolos son: TCP/IP el cual es el protocolo más común para conectar bases de datos por red, ODBC el cual permite que diferentes programas se conecten a las bases de datos y JDBC que se usa cuando las aplicaciones están hechas en Java y necesitan conectarse a la base de datos. Los tres son local y remoto. 
 
1. Investiga si estos motores de bases de datos cuentan con protocolos de copias de seguridad o respaldo.
Sí, casi todos los motores de bases de datos modernos tienen herramientas para hacer copias de seguridad. Estas copias son muy importantes para proteger los datos y poder recuperarlos si pasa algo malo, como un fallo del sistema o pérdida de información.
